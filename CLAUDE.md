# Agentic Workstation - заметки для работы с проектом

Лёгкая быстрая IDE для macOS на Electron и React: вкладки проектов, дерево файлов,
редактор и GUI провайдеров LLM (первый - Claude Code). Пока каркас: раскладка окна из
восьми зон, дерево файлов, самообновление, дизайн-система (плоское тёмное стекло,
ADR 0006, витрина в dev), GUI Claude Code в правой панели (ADR 0009); середина окна -
виды «файл», «сценарии», «статистика», «коннекторы» (ADR 0015, 0029). «Файл» - вкладки и редактор Monaco с
подсветкой shiki и автосохранением (ADR 0018), у Markdown - просмотр (ADR 0019),
сценарии - очереди на уровне IDE с worktree и провайдером-исполнителем (ADR 0039),
статистика - агенты всей машины по транскриптам и человек в окне IDE, в SQLite (ADR 0042). В левой панели, кроме дерева, - изменения проекта
относительно последнего коммита, разница файла открывается вкладкой (ADR 0020). Локальная
история - каждая правка файла (редактор, агент, терминал, git) на 30 дней с возвратом любой
версии, вкладкой в середине (ADR 0045).
Настройки IDE (⌘, или шестерёнка внизу левой полосы; окно с меню разделов) - размер текста: один множитель на все кегли (ADR 0024), и звуки, которыми
разговоры зовут человека; позвавший разговор фонового проекта - точкой на вкладке проекта (ADR 0046).
Терминал - снизу правой колонки, под панелью Claude Code, как в WebStorm (ADR 0037).
Коннекторы к приложениям (Gmail, Calendar, Notion, Slack, любой MCP, коннектор от ИИ) - свой
вид в середине окна: их держит IDE и отдаёт провайдеру через локальный MCP-шлюз, у каждого
проекта свой набор (ADR 0028, 0029). Других MCP у Claude в IDE нет. Браузер для ИИ - встроенный
коннектор Browser: настоящий Chrome человека через своё расширение (`apps/browser-extension`,
ADR 0040). Remote Control - IDE с телефона через свой релей (`apps/relay`, клиент `apps/phone`,
протокол `packages/remote-protocol`, ADR 0041).

Здесь то, что не читается из кода. Карта частей - `docs/architecture.md`, решения и
почему они такие - `docs/adr/`. Правила по конкретным папкам подгружаются сами из
`.claude/rules/`.

## Команды

Из корня:

| Команда                                                 | Что                                                            |
| ------------------------------------------------------- | -------------------------------------------------------------- |
| `pnpm dev`                                              | IDE в режиме разработки. С осмотром окна - скилл `/dev`        |
| `pnpm check`                                            | типы, ESLint, stylelint, тесты, формат - всё, что проверяет CI |
| `pnpm dist:local`                                       | собранное приложение без сертификата (подпись ad-hoc)          |
| `pnpm --filter @agentic-workstation/desktop update:e2e` | сквозная проверка самообновления, ~2 минуты                    |
| `/release`                                              | выпуск версии, только по прямой команде                        |
| `apps/relay/scripts/relay-deploy.sh`                    | выкладка релея и клиента телефона (с проверкой, что это наш)   |

Порты (записаны в `~/.claude/ports.md`): окно Vite `5315`, отладка окна (CDP) `5316`,
локальный манифест обновлений в проверке `5317`, возврат входа коннекторов `5319` (вписан в
Slack app и регистрацию Notion - не менять), релей Remote Control `4460` (локально и в
контейнере), Vite телефонного клиента `3025`. Шлюз коннекторов берёт порт у системы.

## Главные правила

Почти всё ниже держит линтер или хук, а не внимательность. Правило сломалось -
чинить код, а не отключать правило.

1. **Границы частей.** `ui` → только себя; `shared` → только себя; `main` → `main`,
   `shared`; окно: `feature` не видит соседнюю фичу, общее - в `state/`, связка - в
   `workbench/`. Окно не трогает Node и Electron - только `lib/ipc.ts`.
2. **Размер.** 200 строк на `.tsx`, 300 на `.ts`. Перерос - делить по
   ответственности (`.claude/rules/renderer.md`), а не поднимать лимит.
3. **Дизайн-система** (ADR 0006). Значения в стилях - только токены `var(--...)` из
   `packages/ui/src/styles/tokens.css`. Новое - по ступеням «готовое → вариант →
   композиция → новый примитив / токен» (`.claude/rules/design-system.md`) и сразу в
   витрину и README пакета - это держит тест. Объёма нет (блики, градиенты, тени у
   контролов) - держит stylelint.
4. **IPC - один контракт** `apps/desktop/src/shared/ipc/contract.ts`. Предметное
   состояние (проекты, файлы, обновления) принадлежит главному процессу, окно держит
   зеркало в кэше React Query под одним ключом. Интерфейсное - в Zustand.
5. **Тексты интерфейса** - только через i18n (`locales/en.json`, `t('...')`).
   Интерфейс по-английски.
6. **GUI Claude Code - своя реализация** (ADR 0009): `main/claude/` ведёт CLI,
   `features/claude-code` рисует нашими примитивами. Код amazing-claude-code не
   копировать - поведение и протокол CLI брать из него как из справочника.
7. **Решение, к которому не хочется возвращаться**, - ADR (`/adr`).

## Проверка своей работы

- Всегда - `pnpm check`.
- Тронул интерфейс - посмотреть на окно (`/dev`: запуск, скриншот через CDP, погасить).
- Тронул обновления, `electron-builder.yml` или скрипты сборки - `update:e2e`.
- Запустил процесс - погасил в том же заходе.

## Грабли

- **Electron 43+ не качает бинарник на установке**, а electron-vite и electron-builder
  без него падают. Его ставит `apps/desktop/scripts/install-electron.mjs` на
  postinstall.
- **`fs` в главном процессе считает `app.asar` папкой.** Удалять и копировать бандл
  приложения - только `node:original-fs`, иначе `ENOTEMPTY`.
- **dev живёт в своей папке состояния** («Agentic Workstation Dev»), отдельно от
  установленной IDE - иначе dev закрывался бы как второй экземпляр, пока открыта
  установленная. Изолированный профиль - `AGENTIC_WORKSTATION_PROFILE_DIR`.
- **TypeScript 6, не 7:** typescript-eslint пока не поддерживает 7 (ADR 0002).
- **Prettier сортирует импорты** (плагин `prettier-plugin-auto-sort-imports`), хук
  после правки прогоняет его по файлу. Не бороться с порядком.
- **`clsx` - условием, не объектом:** `clsx(styles.a, isActive && styles.active)`.
  Объектная форма с `styles.x` ключом не компилируется при `noUncheckedIndexedAccess`.
- **dev человека не трогать.** Обычно у него запущен свой `pnpm dev`: не гасить, не
  перезапускать, не править его профиль («Agentic Workstation Dev»). Смотреть на окно - в
  отдельной копии (`apps/desktop/scripts/agent-window.sh`, скилл `/dev`). Правки
  `src/main` его dev всё равно перезапускают - так работает `--watch`.
- **Область перетаскивания окна.** Нажатие по ней macOS забирает себе, страница его
  не видит, а кнопка внутри неё дрожит: hover пропадает на каждом втором движении
  мыши. Поэтому область - только пустые распорки (миксин `window-drag-region`), а
  «клик мимо» на ней для всплывающих панелей решает тот же миксин. CDP этого не
  покажет: его события до страницы доходят. Проверка настоящей мышью - скилл `/dev`.
- **Системные диалоги** (выбор папки, «где создать проект») CDP не нажмёт. Проекты в
  копию передаются папками при запуске. Меню проекта и ветки - обычные панели в
  странице, их CDP видит и кликает.
- **Редактор в копии пишет в настоящие файлы.** Автосохранение не спрашивает: набранное
  в копии через секунду уже на диске проекта человека. Печатать и проверять запись -
  только в своей временной папке-проекте (передать её в `agent-window.sh start`), его
  репозитории - лишь смотреть.
- **Действия git в копии - только на чтение.** Проекты в ней - настоящие репозитории
  человека: открыть меню и диалог можно, переключать ветки, создавать, пушить - нет.
  Поведение git проверяют тесты на временных репозиториях (`main/git/*.test.ts`).
- **Отдельный профиль не трогает связку ключей.** С `AGENTIC_WORKSTATION_PROFILE_DIR` (окно
  агента, `update:e2e`) IDE идёт с `use-mock-keychain`: иначе копия с другой подписью вставала
  на окне macOS «разрешить доступ к Agentic Workstation Safe Storage». Секреты копии живут до
  её выхода.
- **Браузер и релей проверяются сквозными тестами по переменной:**
  `AGENTIC_WORKSTATION_BROWSER_E2E=1` - настоящий Chrome for Testing с расширением (манифесты
  host - только во временный профиль, не в браузеры человека);
  `AGENTIC_WORKSTATION_REMOTE_LIVE_RELAY=wss://agentic-workstation-relay.mzpizote.com` - пара и
  команды через боевой релей.
- **Подпись.** Сертификат `Agentic Workstation Code Signing` один навсегда: новый отключит
  обновления у всех установленных копий. Копия - `agentic-workstation-code-signing.p12` в
  корне (git её не видит), не удалять. Подписывает хук `scripts/sign-app.cjs`, а не
  electron-builder: так не нужно доверие к сертификату и окно с паролем
  (`docs/code-signing.md`).

## Язык

Комментарии и JSDoc - по-русски, объясняют «почему», а не «что». Идентификаторы,
файлы, коммиты - по-английски.
