# Интонация вопроса во Flux TTS

Замер к ADR 0135: произносит ли синтез вопрос вопросом. `tts.mjs` синтезирует фразы одним ходом,
как ответ звонка, `pitch.py` печатает высоту тона за последние 0,6 с фразы по 0,1 с
(автокорреляция по 10 мс, нужен numpy).

```sh
set -a && . ~/.claude/secrets/lifelog.env && set +a   # DEEPGRAM_API_KEY
node tts.mjs flux-olga-ru /tmp/s.wav "Понятно."
node tts.mjs flux-olga-ru /tmp/q.wav "Понятно?"
python3 pitch.py /tmp/s.wav /tmp/q.wav
```

Ровный или падающий хвост - утверждение, подъём к концу (или подъём на ударном и спад на
заударном, русская ИК-3) - вопрос. Октавные ошибки автокорреляции бывают: смотреть на ход, а не
на одну цифру.
