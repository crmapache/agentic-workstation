## Решения владельца (2026-11-21)

- **Телефон - только веб** (нынешний PWA). Родного приложения нет. Пока идёт звонок, экран не
  гаснет (Wake Lock); заблокировал телефон или ушёл в другое приложение - звонок на паузе
  (микрофон и озвучка стоят, IDE держит сессию), вернулся - продолжается.
- **Чат создаётся в проекте Home** IDE (`~/.agentic-workstation/home`), не в `~`: `~` отклонил
  ADR 0059.
- **Голос и на компе** - кнопкой в панели, микрофон и динамики компа, тот же конвейер.
- **Ключ для живых проверок** - из `~/.claude/secrets/lifelog.env` (DEEPGRAM_API_KEY), только в
  своей копии IDE и пробах; в репозиторий, журнал и чат не попадает.

## Решения агента (сказаны владельцу, возражений нет)

- **Вариант A спецификации** - свой конвейер в главном процессе: Flux STT `/v2/listen`
  (`flux-general-multi`) и Flux TTS `/v2/speak`. Voice Agent API (B, C) требует публичного адреса
  IDE, его нет.
- **Голоса** - выбранные владельцем на слух 2026-11-14: `flux-olga-ru`, `flux-carmen-es`,
  `flux-paige-en`, `flux-mariana-pt`; для остальных языков из десяти - первый голос языка из
  каталога. Ожидаемые языки по умолчанию - ru, en, es, pt.
- **Голосовые правила - скрытой пометкой к каждой реплике голосом** (как заметка редактора), а
  не добавкой к системному промпту: CLI читает промпт только при запуске. Звонок кончился -
  пометок нет, агент снова отвечает подробно. Работает у любого провайдера без перезапуска.
- **Провайдер** - по умолчанию Claude Code, выбор строкой в настройках; модуль голоса работает
  через общий порт панелей (тот же, что у телефона), без привязки к провайдеру.
- **Звук только через релей**, ключ Deepgram не покидает комп (Vault, как ключи коннекторов).
- **Звук внутри SEALED-кадров** двоичным телом: релей не меняется, кроме заголовка
  `permissions-policy` (микрофон странице сейчас запрещён). Тело с первым байтом `{` - JSON, как
  раньше; первый байт `0x01`/`0x02` - аудиокадр по заголовку спецификации (8 байт: тип, флаги,
  резерв, номер кадра).
- **Пуш на телефон**, когда голосовой разговор доделал работу уже после звонка.
- **Вкладка на компе** появляется в Home, окно вперёд не выводится.
- **Новый ADR 0104** заменяет «голос не делаем» в ADR 0009, 0010, 0041.
- **Политика конфиденциальности сайта** - поправить до кода, который шлёт звук в Deepgram
  (правило главного процесса про новые внешние пути данных).

## Факты и замеры

- 2026-11-21, проба `/tmp/voice-probe/probe.mjs` (Node 24, глобальный WebSocket, авторизация
  подпротоколом `['token', key]`): `flux-olga-ru`, linear16 16 кГц - первый звук через 972 мс
  от открытия соединения (вместе с рукопожатием), 4 с речи = 128000 байт, куски по 2560 байт.
  Конец звука хода - `SpeechMetadata` (не `Flushed`).
- Та же речь кадрами по 80 мс в `/v2/listen?model=flux-general-multi&language_hint=ru&...`:
  `StartOfTurn` с первым словом, `EndOfTurn` (trigger `model`) с `languages: ["ru"]`;
  «Привет.» с паузой после него - отдельный ход. Короткие реплики надо склеивать с
  последующими.
- TTS: сервер закрывает сессию после 60 с без сообщений клиента (NET-0004) - держать
  `Configure` раз в 30 с; `Interrupt.playback_offset` - мс от начала сессии, каждое следующее
  дальше прошлого; `text_spoken` приходит только с offset.

## Устройство

### Главный процесс - `apps/desktop/src/main/voice/`

- `deepgram/` - `flux-listen.ts` (STT: кадры, TurnInfo, Configure языков, переподключение
  0.5/1/2/4 с с буфером до 5 с), `flux-speak.ts` (TTS на голос: Speak, Flush, Interrupt,
  Configure скорости, keepalive), `deepgram-key.ts` (проверка ключа `GET /v1/auth/token`).
- `voice-settings.ts` - настройки (`voice.json` в userData) и ключ (`voice.vault`); каналы
  `voice:*`.
- `call/` - звонок: состояния (connecting, listening, thinking, working, speaking,
  reconnecting, paused, ended), склейка ходов Flux в реплики, язык реплики, озвучка ответа по
  предложениям с фильтром (код, таблицы, URL, разметка), двухшаговое перебивание, подтверждения,
  тишина.
- `voice-note.ts` (в `agents/conversation/`) - скрытая пометка к реплике и её разбор при
  повторе журнала, как `editor-note.ts`.
- Конечные точки звонка: окно IDE (каналы IPC) и телефон (мост Remote Control) - один интерфейс.

### Телефон и релей

- `packages/remote-protocol`: сообщения `voice.*` (spec, раздел «Протокол через релей»), кадры
  звука в теле SEALED, способность `voice` в inventory.
- `apps/relay/src/headers.ts`: `microphone=(self)`.
- `apps/phone`: кнопка «Voice» у IDE, экран звонка (статус, живой текст, Stop, Mute, End,
  карточка подтверждения), захват AudioWorklet → PCM16 16 кГц кадрами 80 мс, воспроизведение
  Web Audio с буфером 100-200 мс и отчётом `voice.playback` раз в 200 мс, Wake Lock, пауза по
  `visibilitychange`.
