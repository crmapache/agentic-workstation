5. Только потом код. Не переделывать то, что журнал называет готовым и проверенным,
   без новой причины, записанной в журнал.

## Решения владельца (ответы на вопросы, 2026-11-10 вечером)

Это не обсуждается заново ночью.

- **Порядок:** сценарии → статистика → браузер → Remote.
- **Worktree - на ветку сценариев целиком.** Галочка в окне запуска при создании новой ветки.
  Все сценарии ветки идут друг за другом в одном worktree, следующий видит результат
  предыдущего. Сценарий, добавленный в существующую ветку, работает там, где она.
- **Worktree - вне проекта и остаётся после завершения.** Папка
  `~/.agentic-workstation/worktrees/<проект>-<хеш>/<ветка>`, своя git-ветка от текущего HEAD.
  После завершения worktree и git-ветка остаются, на карточке ветки кнопки «Открыть как
  проект» и «Удалить» (с вопросом). Если ветка не оставила ни коммитов, ни изменений -
  worktree удаляется сам.
- **Git ночью:** ветка `feat/scenarios-stats-browser-remote`, коммит после каждого
  законченного и проверенного этапа, **без push**. Правка PLAN.md - в первом коммите.
- **Браузер управляет вкладкой через отладчик Chrome** (`chrome.debugger`, CDP), и только на
  время работы: подключился к вкладкам агента, закончил - отключился, плашка Chrome «начал
  отладку» видна только пока идёт работа.
- **Доступ ИИ к вкладкам - все вкладки профиля.** ИИ может сам перечислить открытые вкладки и
  взять любую. Ссылка «скопировать ID вкладки» остаётся как быстрый способ указать нужную.
- **Статистика агентов - вся машина**, с разбивкой «в IDE / вне IDE» и фильтром. История - из
  журналов Claude Code за всё, что ещё лежит на диске.
- **Статистика сверх четырёх обязательных пунктов:** токены и стоимость; когда и как работает
  человек (календарь, серии, часы пика, работа агентов без человека); сценарии и инструменты.
  **Достижений не делать** - «они тут не нужны».
- **Remote Control - отдельный, на своём домене.** ACC и его релей не трогать вообще, только
  смотреть как справочник. Релей и телефонный клиент живут в этом репозитории.
- **Домен релея - `agentic-workstation-relay.mzpizote.com`.**
- **Выкладку релея делаю сам ночью:** запись в Cloudflare, приложение в Coolify, выкатка (скилл
  `infra`). Релеи ACC (`acc-relay`, `acc-relay-dev`) и Codex (`acx-relay`) не трогать: скрипт
  выкладки должен отказываться работать с чужим приложением, как у `acx-relay`.

## Общий фундамент (делается внутри первой части)

**Слой провайдеров в главном процессе - `main/providers/`.** Сейчас его нет: всё в
`main/claude/` про Claude. Полную переделку `ClaudeService` под провайдеров ночью не делаем
(риск сломать панель), но всё новое (сценарии, статистика, Remote) говорит с провайдером через
узкий интерфейс, а не с `ClaudeService` напрямую:

- `ProviderId` (`'claude'` сейчас), описание провайдера: имя, иконка, доступен ли CLI, модели.
- Сессия агента для движков (сценарии): открыть или продолжить, послать сообщение, события
  (конец хода с текстом, вопрос-разрешение, лимит, падение), прервать, закрыть. Реализация
  Claude - на `CliProcess` и `cli-args`, как `scenario-session.ts` архива.
- Одноразовый вопрос модели с ответом по схеме (имя ветки) - через уже существующий
  `structured-ask.ts`.
- Источник статистики провайдера (журналы на диске, живые события).
- Окно получает список провайдеров через IPC и рисует выбор провайдера общим компонентом.

Подробности - в [10-scenarios.md](10-scenarios.md), раздел «Провайдеры».

## Вопросы на утро

Сюда - то, что ночью решил сам, но владелец может захотеть иначе.

- **Сценарии: слово «Queue» в интерфейсе** вместо «Branch»: у очереди с worktree есть ещё
  git-ветка, два «branch» путали бы. Поменять - строки i18n.
- **Очереди закрытого проекта продолжают работать** (решение ночью, ADR 0039): сценарии на
  уровне IDE, доска показывает все очереди. Если надо гасить их вместе с вкладкой, как терминал, -
  одна правка в сервисе.
- **Worktree без зависимостей:** `node_modules` в worktree не копируется, агент ставит сам; файлы
  из `.worktreeinclude` (как в Claude Code) копируются.
- **Run now в расписании** запускает сразу с ответами из записи часа, без окна запуска.
- **Статистика: правки файлов командами Bash** (`toolUseResult.bashEditDiff` - в 5 раз больше
  строк, чем у Edit) считаются кодом агента, кроме git checkout/pull/merge, форматтеров и
  менеджеров пакетов. Сообщения, которые шлют через SDK другие приложения (callmate), от
  человеческих не отличить - считаются человеческими.
- **Токен npm попал в журнал сессии.** Агент браузера по ошибке вывел строку из `~/.npmrc` с
  токеном: в файлы и наружу она не ушла, но лежит в журнале этой сессии Claude Code. Лучше
  выпустить новый токен на npmjs.com и заменить его в `~/.npmrc`.
- **Браузер: публиковать ли расширение в Chrome Web Store** (сейчас «Load unpacked», постоянный
  id `mdlbfahcfjmnkgbmpfjdppaljimjmknc`, закрытый ключ - `agentic-workstation-extension-key.pem` в
  корне, git его не видит; не удалять - без него id сменится).
- **Браузер: спрашивать ли подтверждение** в окне расширения, когда ИИ нажимает кнопку отправки
  формы. Сейчас не спрашивает: доступ решают ступени коннектора, загрузка файлов - ступень
  «отправка».
- **Браузер: группа вкладок агента названа по проекту**, а не по разговору: имени разговора
  мост в момент открытия вкладки не знает.
