# Часть 2. Статистика

Требования - раздел «Статистика» в [PLAN.md](../../PLAN.md), решения владельца - в
[README.md](README.md). Прошлые записи: ADR 0010 (статистика панели ACC с достижениями убрана,
статистика будет своя у IDE и по всем провайдерам), ADR 0015 (вид середины «Statistics»,
сейчас заглушка).

## Что показываем

Обязательное от владельца:

1. **Код руками** - строки, добавленные и удалённые человеком в редакторе IDE, и набранные
   знаки (вставка считается отдельно).
2. **Код агентами** - строки, добавленные и удалённые агентами (успешные правки файлов), и
   число затронутых файлов.
3. **Время работы агентов** - сумма времени ходов (агенты параллельно складываются) и
   «настенное» время, когда работал хотя бы один.
4. **Время присутствия человека** - минуты, когда человек реально что-то делал в окне IDE.

Сверх того (выбор владельца, достижений нет):

- **Токены и стоимость** по провайдерам, моделям, проектам, по часам и дням; сравнение с прошлым
  таким же периодом; доля кеша; стоимость «на ценах API».
- **Когда и как работает человек:** календарь активности на год (как GitHub), серия дней
  (текущая и лучшая), часы и дни пика одной фразой, рабочие сессии (куски присутствия с
  разрывом больше 30 минут), **сколько агенты работали без человека** (минуты работы агентов
  вне минут присутствия).
- **Сценарии:** прогоны, доля успешных, среднее время и цена прогона, самые частые сценарии.
- **Инструменты:** чаще всего вызываемые инструменты, коннекторы (MCP по серверу), вопросы
  разрешений в IDE: спрошено, разрешено, отказано.
- Мелочи, которые дешёвые и интересные: число разговоров и сообщений человека, модели долей,
  доля кода агентов от всего кода.

## Откуда берутся числа

| Что                     | Источник                                                                                                                                                                              | Точность                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Токены                  | Транскрипты Claude Code `~/.claude/projects/**/*.jsonl`, включая `subagents/` на любой глубине; `message.usage`, без дублей по `message.id + requestId` (как `transcript-answers.ts`) | точно                                                                                 |
| Стоимость               | Токены × таблица цен моделей (скилл `claude-api` - актуальные цены), кеш чтения и записи - своими множителями                                                                         | «на ценах API», не счёт подписки                                                      |
| Строки агентов          | `toolUseResult.structuredPatch` у успешных Edit/Write/MultiEdit в транскрипте; нет его - разность `old_string`/`new_string` с обрезкой общих строк (как `EditLines` ACC)              | точно / близко                                                                        |
| Время агентов (в IDE)   | Живые часы хода панели и сценариев (`work-clock.ts`: без ожидания ответа человека)                                                                                                    | точно                                                                                 |
| Время агентов (вне IDE) | Транскрипт: ход от сообщения человека до последней записи перед следующим, промежутки между записями больше 15 минут не считаются                                                     | оценка, помечена в интерфейсе                                                         |
| Присутствие             | Окно: клавиатура, мышь, прокрутка при фокусе окна; минута «присутствия» - если ввод был не дольше 3 минут назад                                                                       | точно по определению                                                                  |
| Код руками              | Редактор: при каждом сохранении - разность сохранённого и прежнего текста (обрезка общих начала и конца), без подгрузок с диска; набранные и вставленные знаки - из событий Monaco    | точно                                                                                 |
| Сценарии                | Хранилище прогонов части 1 (запись итога прогона в базу статистики по его концу)                                                                                                      | точно                                                                                 |
| Инструменты             | `tool_use` в транскриптах (всё), вопросы разрешений - живые события панели                                                                                                            | точно                                                                                 |
| «В IDE / вне IDE»       | Список сессий, которые запускала IDE (разговоры панели, сессии сценариев), - своя таблица; остальное в транскриптах - «вне IDE»                                                       | точно с момента появления статистики, для старых разговоров панели - по `claude.json` |

Проект транскрипта - по `cwd`: ближайший открытый или недавний проект выше по пути; worktree
сценариев (`~/.agentic-workstation/worktrees/...`) - их исходный проект по очередям части 1;
иначе ближайшая папка с `.git`; иначе сама папка.

История: при первом запуске фоном читается всё, что лежит в `~/.claude/projects` (CLI хранит
около 30 дней). Код руками и присутствие считаются с момента выпуска - истории для них нет, и
окно это честно говорит.

## Хранение - SQLite (`node:sqlite`)

`userData/statistics.sqlite`. Почему не JSON, как остальное: статистика - много мелких записей
и выборки по периодам, проектам, источникам; книга в JSON (как в ACC) пришлось бы читать
целиком и складывать в памяти. `node:sqlite` встроен в Node 24 из Electron 44 - без нативного
модуля и пересборки (проверено: `DatabaseSync` работает при `ELECTRON_RUN_AS_NODE`; **первым
делом проверить в настоящем главном процессе из бандла electron-vite**, при отказе - запасной
путь: файлы JSONL по дням и сложение в памяти, записать в журнал).

Таблицы (ориентир):

- `files(path PK, size, mtime_ms, offset)` - где остановилось чтение транскрипта (дочитываем
  только новое, укоротившийся файл - заново).
- `answers(key PK, provider, hour, project, session, model, input, output, cache_read, cache_write)`.
- `edits(key PK, provider, ts, project, session, tool, ext, file_hash, added, removed)`.
- `tool_calls(key PK, provider, ts, project, session, tool, server)`.
- `prompts(key PK, provider, ts, project, session)`.
- `turns(key PK, provider, session, project, started_at, ended_at, work_ms, exact)`.
- `ide_sessions(provider, session PK, kind 'panel' | 'scenario', seen_at)`.
- `presence(day, minute, project, PRIMARY KEY(day, minute, project))`.
- `manual(minute, project, ext, typed, pasted, added, removed)` - сложено по минутам.
- `permissions(ts, project, session, decision)`.
- `scenario_runs(run_id PK, provider, project, scenario, started_at, ended_at, state, cost, tokens, active_ms)`.

Время - UTC в мс; дни и часы для графиков - по местному поясу при выборке, как в ACC (часы
храним эпохой, в дни переводим на выходе).

Чтение транскриптов - в отдельном потоке (`worker_threads`): первый проход может быть по
гигабайтам, главный процесс не должен замирать. Поток пишет в ту же базу (WAL).

## Код - `main/statistics/`

- `stats-db.ts` - открытие базы, схема, миграции по номеру версии.
- `transcripts/` - обход, дочитывание по смещению, разбор строк (usage, tool_use, tool_result
  с `structuredPatch`, сообщения человека, время), проекты по `cwd`. Поток `scan-worker.ts`.
- `live/` - приём живых событий: ход панели кончился (сессия, точное время работы), вопрос
  разрешения, сессия сценария; из окна - пачки присутствия и правок руками.
- `queries/` - сводки по периоду и фильтрам, сравнение с прошлым периодом, календарь, серии,
  часы пика, «агенты без человека».
- `stats-service.ts` - всё вместе, событие окну `stats:changed` не чаще раза в 30 секунд.

Живые события панели Claude: в `ClaudeEvents` добавить узкие колбэки (конец хода, решение по
разрешению), как уже сделано с `onState`/`onFeed`, без чтения внутренностей панели.

Окно → главный процесс: `stats:noteActivity` пачкой раз в 30 секунд и при уходе из окна:
минуты присутствия с проектом, правки руками по минутам.

- Присутствие - хук в `workbench/` (окно целиком, а не одна фича): слушатели ввода на
  документе в фазе захвата, только при фокусе окна, минуты набираются в памяти.
- Правки руками - `features/editor/editor-document.ts`: при сохранении своей правки (не
  `adopt` с диска, не возврат куска из коммита) считается разность с прежним сохранённым; знаки -
  из событий изменения модели, вставка - через `onDidPaste`.

## Окно - `features/statistics`

Раскладка по ADR 0030: `PageHeader` («Statistics», выбор периода Today / 7 days / 30 days / All
time, фильтры: источник All / In IDE / Outside IDE, проект All / This project), дальше разделы
`Section`. Каждое число со сравнением с прошлым таким же периодом, где сравнение честно
(прошлый период не раньше начала данных).

1. **Overview** - четыре плитки: код (ты / агенты, полоса долей), время агентов (сумма и
   настенное), твоё присутствие (часы, сессии), токены и стоимость.
2. **Code** - столбцы по часам или дням: строки руками и агентами рядом; языки по расширениям.
3. **Time** - присутствие и работа агентов по часам или дням; «агенты работали без тебя N ч».
4. **When you work** - календарь за год, серии, фраза про пик («чаще всего Вт-Чт, 10:00-13:00»).
5. **Tokens & cost** - столбцы, разбивка по моделям и проектам, доля кеша.
6. **Scenarios** - прогоны, успешные, среднее время и цена, частые сценарии.
7. **Tools** - частые инструменты, коннекторы, разрешения.

Графики - новые примитивы в `packages/ui` (их семантики там нет): столбцовая диаграмма (одна или
две серии, ось из трёх линий, подсказка по наведению), календарь-тепловая карта, полоса долей.
Перед первым графиком - скилл `dataviz`. Цвета - роли токенов (`--color-gauge-*`, акцент),
никаких новых сырых значений. Архивные `StatsHeatmap`, `StatsHourBars`, `StatsLineChart` -
справочник. Каждый новый примитив - строка README пакета и образец в витрине (иначе падает
`showcase.coverage.test.ts`), ADR на графики.

## Риски

- Объём транскриптов: если гигабайты - первый проход долгий; окно показывает «считаю» и
  частичные числа.
- Формат транскриптов меняется версиями CLI - разбор терпим к незнакомому, незнакомое
  пропускается, не роняет проход.
- Цены моделей: брать из скилла `claude-api` в момент работы, записать дату цен в коде.
