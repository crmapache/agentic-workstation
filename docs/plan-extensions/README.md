# Расширения IDE (Extensions) - план и журнал

Просьба владельца (2026-11-19): раздел плагинов, чтобы каждый человек мог с ИИ написать свой
плагин и поменять почти любое поведение IDE; ручки чётко ограничивают инвазивность, но
максимально широкие. Работа - в рабочей копии `agentic-workstation-plugins`, ветка
`feat/plugins`, без push.

## Как читать после сброса контекста

Решения ниже окончательные. Журнал внизу - что сделано и что дальше.

## Решения

- **Имя - Extensions**, а не Plugins: «плагины» в IDE уже - плагины Claude Code (экран панели,
  каналы `plugins:*`, `PluginsScreen`). Код, каналы, папки - `extensions`.
- **Где живёт расширение:** папка `~/.agentic-workstation/extensions/<id>/` (у копии с профилем -
  `<профиль>/extensions`): `extension.json` (манифест) и `main.js` (ES-модуль). Включено, выданные
  права, хранилище и настройки - в userData (`extensions.json`, `extensions-data/`, секреты - Vault).
- **Исполнение - песочница QuickJS (WASM)** в одном потоке-воркере главного процесса: у каждого
  расширения свой модуль WASM со своей памятью (потолок 64 МБ), прерывание по сроку на каждый
  синхронный кусок (1 с), модули - только из своей папки. Ни Node, ни DOM, ни сети: всё через
  глобальный `ide`, каждый вызов - JSON через один мост `host(method, payload)`. Замер: вечный
  цикл обрывается за 100 мс, память сверх потолка - исключение внутри песочницы, IDE живёт.
- **Права (capabilities)** объявлены в манифесте, выдаёт человек на виде Extensions. Шире выданного -
  расширение стоит «ждёт одобрения», уже - работает. Без прав: команды, виды, строка состояния,
  уведомления, диалоги, тема, своё хранилище и настройки, таймеры, журнал. С правами:
  `files.read`, `files.write`, `agent.observe`, `agent.intercept`, `ide.control`, `ai.tools`,
  `network` (+ `network.hosts`), `shell` (+ `shell.commands`), `clipboard`.
- **Интерфейс расширения - декларативное дерево** из примитивов дизайн-системы (stack, row,
  section, card, text, markdown, code, badge, button, поля, switch, select, list, keyValue,
  progress, empty, divider). Своего HTML и CSS нет: расширение не ломает раскладку и стиль.
  Тема - только переопределение токенов `--color-*`, `--palette-*`, без `url(`.
- **Хуки разговоров** - нейтральные к провайдеру: перед отправкой (переписать текст), конец хода
  (наблюдать), охрана разрешений (только отказать, разрешить нельзя). Каждый хук с тайм-аутом.
- **Инструменты для ИИ** - встроенный коннектор `extensions` (сервер `extensions`), список
  инструментов живой, смена - `serverChanged`.
- **Создание с ИИ** - кнопка «New extension»: IDE кладёт заготовку с руководством (`AGENTS.md`,
  `CLAUDE.md`, `ide.d.ts`), открывает папку проектом и новый разговор выбранного провайдера с
  просьбой человека. Расширение перезагружается само при правке файлов; ИИ проверяет его
  инструментами `workstation`: `list_extensions`, `extension_logs`, `reload_extension`,
  `run_extension_command`.

## Журнал

- 2026-11-19: разведка кода, проба QuickJS (изоляция, асинхронный мост, срок, память), план.
- 2026-11-19: главный процесс готов - движок (`main/extensions/engine/`), манифест и права,
  ручки (`host/`), сервис, хуки разговоров в ядре (`agents/hooks/`, `runtime.hold`, outbox),
  коннектор `extensions`, инструменты workstation для ИИ, заготовка и руководство
  (`authoring/`). Все проверки главного процесса зелёные. Дальше - окно, потом магазин.
- Владелец добавил (2026-11-19): общий магазин расширений на сервере - публикация, каталог для
  всех, оценки и отзывы, установка и обновления внутри IDE. Выкладка сервера - только после его
  «да».
- 2026-11-19: окно готово - вид Extensions (Installed, Store), окно расширения (одобрение прав с
  риском, настройки и секреты, вклад, журнал, публикация), новое и правка с ИИ, виды расширений
  своими иконками, команды в поиске и на клавишах, пункты строки состояния, вопросы окном, тема на
  корне документа, Monaco и терминал перечитывают её. Магазин: `apps/store` (Node, SQLite) и
  `packages/store-protocol`; в IDE - каталог, карточка с отзывами, установка со сверкой отпечатка,
  обновления, публикация, отзывы.
- 2026-11-19: живая проверка в копии окна с локальным магазином: два расширения из папки (одно ждёт
  одобрения, одобрено - инструмент ИИ в коннекторе `extensions`, охрана), вид Pomodoro (поле
  переживает перерисовку, таймер в строке состояния, клавиши ⌥⌘P), установка из магазина с правами,
  публикация из окна, тема и её снятие. «New extension» на Claude: заготовка, проект, разговор;
  Claude за 55 с написал расширение и сам проверил его `list_extensions`, `extension_logs`,
  `run_extension_command`, `reload_extension`.
- Не сделано и ждёт владельца: выкладка магазина (приложение Coolify `aw-store`, том `/data`, домен
  agentic-workstation-store.mzpizote.com, потом `apps/store/scripts/store-deploy.sh`), коммит ветки.
