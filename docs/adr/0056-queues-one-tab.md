# 0056. Очереди одной вкладкой: свои полосами сверху, других проектов - плотными карточками ниже

- **Статус:** Принято
- **Дата:** 2026-11-13

## Контекст

ADR 0039 дал виду сценариев две вкладки очередей: Queues - очереди текущего проекта полосами с
управлением, All queues - доска очередей всех проектов, плотными карточками по проектам, со
сводкой «столько-то идёт, столько-то ждёт». Страница со всеми очередями - пункт владельца: очереди
живут на уровне IDE, переживают закрытую вкладку проекта, и видеть их надо, не переключаясь.

13 ноября владелец посмотрел на обе вкладки и не понял, чем они отличаются. Пока очереди есть
только в одном проекте, а так почти всегда, обе показывают одно и то же, и счётчики у них
одинаковые.

## Варианты

**Оставить две вкладки, переименовать** (This project / All projects).

- Плюсы: правка в двух строках текста.
- Минусы: в обычном случае (очереди в одном проекте) вкладки всё равно показывают одно и то же,
  только другим видом; человек выбирает между двумя видами одних и тех же очередей.

**Одна вкладка с переключателем «этот проект / все».**

- Плюсы: одна вкладка.
- Минусы: тот же выбор, только спрятанный в переключатель; очереди других проектов не видны,
  пока его не нажмёшь.

**Одна вкладка Queues: очереди текущего проекта полосами сверху, ниже раздел «Other projects» с
плотными карточками по проектам; нет других проектов с очередями - нет и раздела.**

- Плюсы: выбирать нечего; в обычном случае вкладка та же, что Queues раньше; когда очереди
  идут в нескольких проектах, всё видно сразу, и к чужой очереди - один переход.
- Минусы: при многих проектах вкладка длиннее; сводка доски «идёт / ждёт» уходит - состояние
  каждой очереди видно на её карточке, ждущая ответа выделена акцентом.

## Решение

Одна вкладка Queues (решение владельца). Главная причина: две вкладки различались только тогда,
когда очереди шли в нескольких проектах, а это редкость, и в остальное время они путали.

## Факты и замеры

Замера нет: решение про понятность, а не про скорость. Вид проверен в копии окна (`/dev`) на
подставленных в кэш окна очередях: три очереди в двух проектах.

## Последствия

- `features/scenarios/BoardTab` удалён, раздел других проектов - `QueuesTab/parts/OtherProjects`;
  группы проектов - `queueGroups`, сводки доски (`boardCounts`) больше нет. Счётчик вкладки -
  все открытые очереди.
- «Go to project» делает проект текущим, вкладка остаётся той же: его очереди встают наверх.
- Доска телефона (`apps/phone`, ADR 0041) - свой экран машины, её не касается.
- Пересмотреть, если очереди станут обычным делом в нескольких проектах сразу и раздел других
  проектов начнёт вытеснять свои очереди.
