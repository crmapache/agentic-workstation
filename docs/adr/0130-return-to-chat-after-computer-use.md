# 0130. Работа на компьютере кончилась - IDE выходит вперёд с её чатом

- **Статус:** Принято
- **Дата:** 2026-11-26

## Контекст

Агент работает на компьютере (Computer Use, ADR 0057) в чужих приложениях: Chrome, Finder,
Системные настройки. Окно IDE при этом уходит назад. Агент кончил и ответил в чате, а человек
смотрит на приложение, где тот работал, и возвращается в IDE руками: переключается на неё, ищет
проект и вкладку. Владелец попросил, чтобы IDE сама выходила вперёд с чатом, где шла эта работа.

Ограничения:

- Когда кончилась работа, IDE уже знает: ни хода, ни фона, который разбудит агента (ADR 0065, 0117).
  Компьютер стол отпускает и раньше, после минуты без вызовов, хотя работа ещё идёт.
- macOS не делает фоновое приложение активным по `focus()` окна, нужен `app.focus({ steal })`.
  Windows отдаёт фокус только тому, кто последним получал ввод.
- Фокус, вырванный у человека посреди набора, уносит его буквы в поле чата IDE.
- Раскладка зон (какая панель провайдера открыта) живёт в окне, проекты и вкладки - в главном
  процессе.

## Варианты

**Когда возвращать.**

1. Когда стол отпускает компьютер. Минусы: минута простоя бывает посреди работы, агент пишет код
   или ждёт сборку. IDE выскочила бы вперёд, а вернувшийся к компьютеру агент нашёл бы перед собой
   её вместо своего приложения.
2. Когда встала работа разговора, который в этой работе брал компьютер (выбрано). Плюсы: ровно
   «кончил и ответил». Минусы: если после компьютера агент ещё долго работал в коде, IDE выйдет
   вперёд только в самом конце.

**Когда не возвращать.**

1. Всегда возвращать. Минусы: человек, который уже работает сам (нажал Stop в капсуле, пишет в
   другом окне), теряет фокус, и его набор уходит в поле чата.
2. Не возвращать, если после последнего снимка ИИ был ввод человека (выбрано): то же время
   последнего ввода, что у сверки экрана (ADR 0129). Плюсы: Stop, Pause, любое касание мыши и
   клавиатуры значат «человек здесь и работает сам». Минусы: человек слегка задел мышь, пока
   смотрел, и IDE не выйдет. Тогда всё как раньше, руками.

**Сценарии и задания.** У их прогона нет вкладки панели (ADR 0039, 0080), они идут в фоне, без
человека у экрана. Окно они не трогают: возврат - только к вкладке чата.

## Решение

Агент Computer Use помнит разговоры, которые брали компьютер в нынешней работе. Когда работа такого
разговора встала, а человек после последнего снимка ИИ не трогал мышь и клавиатуру, IDE возвращает
его к чату:

1. открывает проект разговора;
2. выбирает его вкладку;
3. окно открывает панель провайдера;
4. окно IDE выходит вперёд.

Возврат можно выключить в настройках, по умолчанию он включён. Главная причина: «кончил» знает
только конец работы разговора, а не отпускание компьютера, и только ввод человека отличает
«смотрел» от «уже работает сам».

## Факты и замеры

MacBook Pro M5 Pro, macOS 27.2, Electron из проекта, 26 ноября 2026.

- Окно Electron, показанное без активации (`showInactive`), при активной установленной IDE.
  После `show()` и `focus()` передним приложением по `lsappinfo front` стало оно. Так и без
  `app.focus({ steal: true })`, и с ним. Свежезапущенное приложение macOS, видимо, пускает вперёд
  и так, поэтому `steal` оставлен, как велит документация Electron для фонового приложения.
- Агент на настоящих руке и столе с поддельными снимками и свидетелем:
  - разговор, бравший компьютер, возвращается один раз, когда работа встала, и после минуты
    простоя посреди работы тоже;
  - разговор без компьютера не возвращается;
  - ввод человека после последнего снимка и конец процесса разговора отменяют возврат;
  - порядок возврата: проект, вкладка, панель, окно; у прогона без вкладки окно не трогается.

Живой прогон с моделью, которая работает на экране владельца, не делали. Windows не проверяли: машины
нет. Там `moveTop` поднимает окно над остальными, а отдаст ли система фокус, неизвестно.

Повторить: `pnpm --filter @agentic-workstation/desktop exec vitest run src/main/computer`.

## Последствия

- `ComputerAgent` держит множество `used`: отметка - на каждом снимке разговора, снимается концом
  работы, концом процесса и закрытием разговора. Когда работа встала, `finished(key)` зовётся, только
  если `isTouchedSince` (`computer-seen.ts`) не видит ввода человека после последнего снимка.
- Связка Computer с панелями - `computer/computer-chats.ts`: Stop капсулы (ADR 0060) и возврат.
  Ключ вызова у вкладки панели - её id, по нему ищется провайдер и проект. Порядок шагов -
  `return-to-chat.ts`, вывод окна вперёд - `window/raise-window.ts`, событие окну -
  `computer:returned` (панель провайдера открывает `state/computer-return.hooks.ts`).
- Возврат выключается в Settings → Chat, карточка Computer Use, переключатель «Bring me back to the
  chat», по умолчанию включён (просьба владельца). Значение - общая настройка IDE
  `returnAfterComputer` (ADR 0099), главный процесс спрашивает её в момент возврата. Старый файл
  настроек поля не знает, и возврат там включён.
- Пересмотреть, если IDE начнёт выходить вперёд, когда человек этого не ждал (тогда - срок «работа
  кончилась давно, не дёргать»), и на Windows после первой проверки на живой машине.
