# 0035. Playwright - встроенный коннектор с настройками у каждого подключения

- **Статус:** Принято
- **Дата:** 2026-11-10

## Контекст

После ADR 0034 у владельца три своих типа: Playwright (подключения 1 и 2), Notion Web и
Chatkepr. Notion Web - тоже Playwright MCP, только с сохранённым профилем браузера и
закреплённой версией пакета. Владелец ждал на плитке «Playwright / Notion Web» и предложил
сделать Playwright встроенным, как Gmail: браузер для ИИ нужен почти всем, а свой тип на
каждую комбинацию флагов - лишняя сущность.

## Варианты

1. **Оставить Playwright своим типом** и разрешить подключениям одного своего типа разную
   команду. Общий механизм, но «тип» тогда ничего не говорит о том, чем работает
   подключение, а человек снова набирает флаги руками.
2. **Встроенный тип Playwright** с понятными настройками у каждого подключения: профиль
   (чистый на каждый запуск или сохранённый в папке), браузер без окна, версия пакета.
   Команду собирает IDE - та же `npx -y @playwright/mcp@<версия>`, что человек писал в
   Claude Code. Флаги сверх этих не выбрать - для них остаётся своя MCP-команда.

## Решение

Второй вариант: Playwright - такой же встроенный тип, как Gmail, у которого подключения
различаются настройками, а не командой, набранной руками. Работает он движком своей
MCP-команды: своя копия на каждый процесс разговора, входа нет. Имя сервера - тип и подпись
(`playwright-work`). Свои команды, которые узнаются как Playwright MCP (только известные
флаги, без секретов), переносятся сами: имя сервера и команда те же, подпись - из имени
сервера (`playwright-1` - «1», `notion-web` - «Notion Web»); свой тип без подключений
уходит. Импорт из Claude Code узнаёт Playwright так же.

## Факты и замеры

- Перенос проверен на данных того же вида, что у владельца на 2026-11-10 (типы Playwright,
  Notion Web, Chatkepr): три подключения стали Playwright, Chatkepr остался своим, имена
  серверов прежние (`connector-migrate.test.ts`, и вживую в копии окна).
- Конфиг Claude Code владельца запускает Playwright ещё и с `--init-script`: такой сервер
  при импорте не узнаётся встроенным и переносится своей командой.

## Последствия

- Тип `playwright` в `ConnectorKind`, `runsCommand` - общее у него и своей команды.
- Настройки подключения после добавления не меняются - как и у остальных типов; нужен
  другой профиль - новое подключение.
- Пересмотреть, если понадобятся частые флаги сверх этих (`--init-script`, браузер): тогда -
  новые настройки Playwright, а не своя команда.
