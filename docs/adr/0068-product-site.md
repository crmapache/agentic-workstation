# 0068. Сайт продукта: статика из apps/site на agentic-workstation.mzpizote.com

- **Статус:** Принято
- **Дата:** 2026-11-16

## Контекст

У IDE не было своей страницы: установщики лежали в репозитории релизов на GitHub, а как
поставить неподписанную сборку (карантин macOS, SmartScreen на Windows), знал только
`docs/releasing.md`. Нужна простая страница на английском: что это за IDE, ссылки на скачивание
и шаги установки, как у Typist. Адрес - `agentic-workstation.mzpizote.com`.

Ограничения: страница должна выглядеть как сама IDE (дизайн-система ADR 0006), ссылки на
скачивание не должны требовать выкладки сайта к каждому выпуску (`/build` быстрый и сайт не
трогает), на сервере уже живёт десяток приложений на Coolify, и выкладка не должна задевать их.

## Варианты

1. **Страница в `apps-site`** (`apps.mzpizote.com`, обычный HTML и один `style.css`). Сайт уже
   есть, но он для политик и экранов входа Google: свой поддомен там не получить, токенов IDE
   нет, стили разъехались бы с приложением с первой правкой.
2. **Next.js, как у Typist.** Привычно по Typist, но серверный процесс ради одной страницы без
   данных - лишний контейнер с Node, а разметку пришлось бы писать на React без нужды.
3. **Статика из Vite в монорепе (`apps/site`), раздаёт nginx.** Одна HTML-страница, стили SCSS
   на токенах `packages/ui`, немного TypeScript. В контейнере только nginx и готовые файлы.

## Решение

Третий вариант. Сайт живёт рядом с кодом IDE и берёт её токены напрямую
(`@agentic-workstation/ui/tokens.css`), так что палитра, шрифты и шкалы не расходятся с
приложением, а stylelint держит на сайте те же правила (свои крупные кегли и ритм страницы -
в `apps/site/src/styles/site-tokens.css`). Ссылки на установщики - постоянные
`/releases/latest/download/<имя>`, номер версии и размеры файлов страница берёт в момент
открытия с `/release.json`: это ответ API GitHub, который nginx держит в кеше 10 минут.

## Факты и замеры

- Страница целиком: HTML 24 КБ (6 КБ сжатым), стили 28 КБ, скрипт меньше 3 КБ. Главный снимок
  окна в WebP - 66 КБ для экрана 1200 точек, 165 КБ для ретины.
- Проверка вёрстки: `pnpm --filter @agentic-workstation/site check:layout <адрес>` - Chromium и
  WebKit, восемь экранов от 320 до 1920 точек, в том числе с системой посетителя Windows и
  телефоном. 2026-11-16 на боевом адресе - 16 из 16 без горизонтальной прокрутки, битых картинок
  и ошибок в консоли.
- Лимит API GitHub без ключа - 60 запросов в час на адрес. Пока страница спрашивала API прямо
  из браузера, прогоны проверки исчерпали его за полчаса с одного Mac; через кеш nginx сервер
  спрашивает GitHub не чаще шести раз в час при любом числе посетителей.

## Последствия

- Выкладка - `bash apps/site/scripts/site-deploy.sh` (или `pnpm --filter
@agentic-workstation/site deploy`): сборка на Mac, образ с nginx на сервере, приложение
  Coolify `aw-site`, проверка по отпечатку `/version.txt`. Новый выпуск IDE выкладки сайта не
  требует.
- Снимки окна на странице - настоящие, из копии IDE на демо-проекте (`apps/site/README.md`).
  Интерфейс заметно поменялся - снимки переснять, иначе страница показывает старую IDE.
- На сайте, в отличие от окна IDE, есть кольцо фокуса с клавиатуры (ADR 0023 - про окно
  приложения): страницу листают Tab, и без кольца по ней не пройти.
- Пересмотреть, если у продукта появится свой домен, вход или платные планы: тогда понадобится
  сервер, и решение о статике стоит открыть заново.
