# 0060. Капсула Computer Use говорит, что ИИ делает: слова модели о шаге и её последняя фраза

- **Статус:** Принято
- **Дата:** 2026-11-14

## Контекст

Капсула Computer Use (ADR 0057) показывала состояние словом («Thinking», «Using your computer») и
под ним имя проекта разговора, а справа две кнопки с подписями. Владелец 14 ноября посмотрел на
неё в работе: имя проекта ничего не говорит, пока ИИ водит мышью по экрану. Хочется видеть, что
он делает или о чём думает, строкой, которая сменяется перелистыванием снизу вверх, как в
приложениях. Кнопки - только значками, а капсула - чуть шире.

Текст размышлений у нынешних моделей скрыт (пустой блок с подписью), поэтому прочитать мысли
напрямую нельзя.

## Варианты

**Называть действие по самому вызову** («Clicking», «Pressing cmd+t»).

- Плюсы: ничего не просим у модели, работает всегда.
- Минусы: не видно зачем: «Clicking» десять раз подряд человеку ничего не говорит.

**Читать ленту разговора и показывать последнюю фразу ответа модели.**

- Плюсы: между шагами модель обычно и так пишет, что видит и что сделает дальше.
- Минусы: пока рука действует, новой фразы нет; разговор сценария идёт мимо ленты панели.

**Поле `intent` у каждого инструмента Computer** - необязательные слова модели о шаге,
«Opening the File menu».

- Плюсы: строка про сам шаг и на языке разговора; модель заполняет такие поля охотно (как
  `description` у Bash).
- Минусы: модель может его не заполнить; лишние токены на каждом вызове.

## Решение

Все три вместе, по состоянию. Пока рука действует - слова модели о шаге (`intent`), без них - само
действие словами окна (набираемый текст не показывается: им бывает пароль, а капсулу видно на
экране). Пока модель думает между шагами - её последняя законченная фраза из ленты разговора
(недописанную не берём, иначе строка менялась бы на каждом слове). Сказать нечего - «Thinking…»;
на паузе - «Paused». Фразу из ленты приносит `ide-features`, который знает провайдера: Computer о
лентах Claude не знает. Строка сменяется новым примитивом `RollingLine` (старая уезжает вверх,
новая приходит снизу), кнопки - `IconButton` (Stop - новый вариант `danger`), окно - 420×44
вместо 340×44.

## Факты и замеры

Страница капсулы из сборки с подставным мостом (Playwright, 420×44): кнопки 30 px стоят по
центру, отступ правой кнопки от края (7 px) равен отступу сверху и снизу, строка по центру по
высоте. Смена строки за 260 мс: на 60 мс старая на -4 px и прозрачности 0,73, новая на +6 px и
0,58; на 120 мс -11 px и 0,21 против +1 px и 0,93; после конца старая убрана. Вживую с моделью
не проверено. Выделение фраз - тест `main/claude/feed/latest-saying.test.ts`, шаг из вызова -
`connectors/kinds/computer/computer-tools.test.ts`, стол - `computer/computer-desk.test.ts`.

## Последствия

- Новый инструмент Computer получает `intent` сам (через `schema`) и обязан передать шаг столу
  (`deskCall(call, stepOf(args, ...))`).
- `CapsuleView` - состояние и строка (`activity`), без проекта; проект остаётся только в отказе
  «занято».
- Разговоры сценариев в капсуле показывают только шаги: их ленты идут мимо панели.
- Пересмотреть, если модели снова начнут отдавать текст размышлений: тогда строку между шагами
  можно брать оттуда.
