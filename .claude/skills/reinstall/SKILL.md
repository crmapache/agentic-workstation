# Reinstall

Ставит заново на этом Mac последний опубликованный релиз (его выкладывает `/build`). dmg лежит в
публичном репозитории релизов под постоянным именем, ключи не нужны:

```
https://github.com/<репозиторий релизов>/releases/latest/download/agentic-workstation-mac-arm64.dmg
```

Репозиторий - поле `agenticWorkstation.releasesRepo` в `apps/desktop/package.json`. Только macOS:
Windows-версию человек ставит её установщиком (`docs/releasing.md`), дальше она обновляется сама.

Всё делает `reinstall.sh` рядом с этим файлом. Шаги руками не повторять: каждый из них уже ломался.

## Почему скрипт, а не команды по шагам

- **Скилл запускают из панели самой установленной IDE.** Её закрытие гасит разговор со всеми его
  процессами, и команды после закрытия просто не выполнились бы. Поэтому замену делает отдельный
  процесс в своей сессии (родитель - launchd), а запущенный изнутри IDE он ещё 30 с ждёт, пока
  агент допишет ответ.
- **`pgrep` и `pkill` не видят своих предков.** Из панели IDE `pkill` по её пути её же и не нашёл
  бы. Главный процесс ищет только отвязанный процесс.
- **Тем же бинарником работает мост браузера.** Chrome запускает его с `host.js`, и `pkill -f` по
  пути приложения обрывал бы Chrome связь с IDE. Главный процесс - точное совпадение командной
  строки (`pgrep -x -f`), а мост сам переподключится к новой IDE за полторы секунды.
- **Закрывать силой нельзя.** Выход IDE дописывает файлы, транскрипты и историю, а файл с
  конфликтом она не бросает, а спрашивает человека. Прежнее «вежливо, через 3 с насильно» теряло
  правки.

## Аргументы

`$ARGUMENTS`:

- пусто - поставить заново, данные остаются: переустановка не должна стирать работу;
- `clean` - чистый лист: удалить и данные IDE;
- `check` - только скачать и проверить установщик, показать версии и что удалил бы `clean`.
  Ничего не закрывает и не меняет.

## Как запустить

Из корня репозитория, таймаут Bash - 600000:

```
bash .claude/skills/reinstall/reinstall.sh $ARGUMENTS
```

Сначала скрипт скачивает установщик и проверяет, что внутри наше приложение. Не скачался или
чужой bundle id - стоп, ничего не тронуто. Дальше по месту запуска:

- **Изнутри установленной IDE** (скрипт пишет «запуск: изнутри установленной IDE») - запускает
  замену и сразу возвращается. Это последний вызов инструмента в ходе: сразу после него - отчёт,
  через 30 с IDE закроется вместе с этим разговором и откроется уже новой.
- **Не из неё** (терминал, dev, копия окна агента) - ждёт итога сам и печатает журнал.

## Что делает замена

1. Бережно закрывает IDE, как ⌘Q. Если она спрашивает про несохранённый файл, через 30 с
   приходит системное уведомление, и скрипт до 10 минут ждёт, пока человек ответит и закроет её
   ⌘Q. Не дождался - отменяет, ничего не тронув.
2. Монтирует установщик, откладывает старое приложение в сторону и копирует новое. Копирование
   сорвалось - возвращает старое и открывает его.
3. С `clean` удаляет данные (список в скрипте). `Application Support/Agentic Workstation` - это
   проекты, вкладки и разговоры, локальная история файлов, настройки, входы коннекторов и
   добавленные аккаунты Claude. Ключ «Agentic Workstation Safe Storage» в связке ключей не
   трогает: без данных он ничего не открывает, а новая установка возьмёт его же.
4. Снимает карантин (без Developer ID macOS иначе пишет «приложение повреждено») и открывает IDE
   с чистым окружением: голый `open` передал бы ей переменные Claude из разговора агента, и
   панель ходила бы в чужой аккаунт.
5. Ждёт, что IDE запустилась, и только тогда удаляет временную папку со старой версией. Не
   запустилась - старая остаётся там, путь в журнале.

О любом сбое после закрытия IDE скрипт сообщает системным уведомлением: разговора к этому
моменту уже нет. Журнал - `~/Library/Logs/agentic-workstation-reinstall.log`, последняя строка
начинается с `ИТОГ:`. Вторую переустановку, пока идёт первая, скрипт не начнёт.

## Чего не трогать никогда

Скрипт этого не трогает, и руками тоже нельзя:

- **dev человека и его профиль** - «Agentic Workstation Dev» в Application Support: это `pnpm dev`,
  не установленная IDE. Ни закрывать, ни удалять, даже с `clean`.
- **Копию окна агента** (`~/.agentic-workstation-agent`) - она своя у скилла `/dev`.
- **Мост браузера** - его процессы в Chrome, `~/.agentic-workstation` и папку расширения
  `~/Agentic Workstation`: расширение загружено в Chrome человека, пропавшая папка выглядела бы
  поломкой браузера.
- **Сертификат подписи и ключ обновлений** в корне репозитория.
- **Разрешения macOS** (TCC): bundle id и сертификат между версиями не меняются, система их
  помнит сама.

## Отчёт

По скиллу `human-output`, коротко.

- **Изнутри IDE** - сразу после запуска скрипта, пока IDE не закрылась: какая версия ставится и
  какая стоит, останутся ли данные, что IDE через 30 с закроется вместе с разговором и откроется
  снова, где журнал. Когда человек вернётся в разговор - прочитать журнал и подтвердить итог
  одной строкой.
- **Не из IDE** - по журналу: версия, данные остались или удалены (что именно), запущена ли IDE.
- После `clean` - что войти в аккаунты Claude и коннекторы придётся заново.
