# Коннекторы к приложениям

Почему так - ADR 0028, карта - раздел «Коннекторы» в `docs/architecture.md`.

- **Вход коннектора не попадает в хранилище провайдера.** Токены - только в `Vault`
  (`safeStorage`), провайдер видит шлюз с ключом своего процесса. Ни `claude mcp add`, ни
  запись в `~/.claude.json` для коннекторов - иначе вход снова уедет вместе с аккаунтом
  Claude.
- **Без шифрования секрет не пишется** (`Vault.set` отказывает). Открытым текстом на диск -
  никогда, даже «временно».
- **Имя сервера - тип и подпись** (`gmail-work`): по нему хук владельца `block-outbound.sh`
  узнаёт отправку (`*gmail*send*`, `*slack*send*`). Тип в начале имени не убирать.
- **Отправка людям - ступень `outbound`**, по умолчанию выключена (`isToolEnabled`), включает
  только человек на виде Connectors. Новый свой инструмент, который что-то отправляет,
  письмо, сообщение, приглашение, ответ организатору, - `outbound`, а не `write`. В
  календаре писать без гостей и с `sendUpdates=none`.
- **Вызов инструмента не повторяется** (`RemoteMcpSource.callTool`): оборвавшийся вызов мог
  выполниться, повтор создал бы второй черновик. Повторять можно только чтение списка.
- **Порт возврата 5319** (`CONNECTOR_REDIRECT_URL`) вписан в Slack app человека и в
  регистрацию Notion, Notion сверяет его строго. Не менять; занят - `callback-busy`.
- **Шлюз** слушает только `127.0.0.1`, проверяет `Host` и ключ процесса разговора
  (`GatewayLaunches`: свой случайный ключ на каждый процесс, хранится хешем, гаснет с
  процессом). Конфиг для CLI - права 600. Ответ - потоком событий с отметками «жив»: долгий
  вызов не рвётся тайм-аутом клиента. Набор серверов поменялся - `serversChanged`
  (перезапуск свободных процессов), поменялось внутри сервера - `serverChanged`
  (`mcp_reconnect`).
- **Браузер открывает только кнопка человека** (`SignInDesk`). Фоновый источник
  (`McpAuthProvider` без `interactive`) при истёкшем входе ставит «нужен вход», а не
  открывает вкладку посреди работы.
- **Коннекторы - вид середины окна** (`features/connectors/ConnectorsView`, зона 6), а не
  раздел настроек: им нужно место. Подключённые - плитками (`Tile` из `packages/ui`) сеткой
  с переносом (заголовок - имя типа, под ним подпись подключения), под ними - каталог нового
  двумя группами: приложения со своими типами и свои способы добавить (адрес, команда, ИИ,
  перенос); сверху шапка вида (`PageHeader`, разделы - `Section`, ADR 0030); подробности,
  выбор проектов и формы - окном по центру (`Modal`, открытое окно держит
  `connectors.store.ts`). Иконка полосы видов середины и поиск везде ведут на этот вид
  (`showMainView`); строки в меню Claude Code у него нет - иконки хватает. Всё, что идёт долго (вход, работа ИИ), живёт в главном
  процессе: уход на другой вид снимает страницу, но не работу.
- **Свой коннектор - тип** (ADR 0034): имя с заглавной, «несколько раз» и образец того, чем он
  работает (`StoredType`, секреты образца - под `typeSecretsKey`). Подключение держит копию
  образца, вход у каждого свой (`DEFINITION_SECRETS` - общее, остальное - нет). Имя сервера
  ставится при создании и с переименованием типа не меняется. Тип «несколько раз» - в
  каталоге рядом с Gmail, удаляется вместе с подключениями; «один раз» уходит со своим
  подключением. Прежний реестр переносит `assignCustomTypes`, импорт группирует так же.
- **Встроенные с официальным MCP** - Notion, Slack, Jira & Confluence, Todoist
  (`REMOTE_MCP_URL`, ADR 0036): адрес держит IDE. Todoist входит личным токеном API
  (способ входа всегда «токен»), остальные - OAuth в браузере. Jira & Confluence - только
  облако Atlassian.
- **Playwright - встроенный** (ADR 0035): команду `npx -y @playwright/mcp@<версия>` собирает
  `playwrightCommand` из настроек подключения (профиль, без окна, версия). Работает движком
  своей команды (`runsCommand`): копия на процесс разговора, входа нет. Своя команда,
  которую узнаёт `playwrightOptionsOf`, переносится в Playwright (`adoptPlaywright`, импорт -
  `asPlaywright`); флаги сверх известных - остаётся своей.
- **Описание коннектора** - слова человека для себя и для модели: шлюз отдаёт его в
  пояснении сервера (`instructionsFor`), смена - `serverChanged` (`mcp_reconnect`). Окно
  сохраняет его само через секунду тишины, при уходе из поля и при закрытии окна, а не на
  каждую букву: каждое сохранение переподключает сервер у живых разговоров.
- **Доступность по проектам** (ADR 0029, 0033): «во всех» - все, без исключений, выбор по
  одному - только у «только в отмеченных». Конфиг `--mcp-config` пишется при подъёме
  процесса (`GatewayHost.open`), проект шлюз узнаёт по ключу процесса, а не по вычислимому
  заголовку. Это фильтр видимости, а не песочница: процесс с Bash прочтёт чужой конфиг в
  userData. Смена доступности - перезапуск только там, где она поменялась. Конфиг не
  записался - разговор идёт без коннекторов и говорит об этом строкой CONNECTORS.
- **MCP-команда - своя копия на процесс разговора** (`LiveConnector.sourceFor`), в папке
  его проекта, всегда, как в Claude Code: два разговора не делят браузер Playwright.
  Общего процесса и переключателя для него нет - параллельной работе нужен второй
  коннектор (ADR 0029). Выключенный коннектор свою команду не запускает, удалённый - не
  поднимает заново.
- **В реестре ключей нет и в аргументах:** аргументы команды и путь адреса с ключом
  хранятся маской, полные - в хранилище (`commandForStore`, `publicUrl`); старые записи
  переносит `moveSecretsToVault`.
- **Коннектор от ИИ - данные, а не код.** Описание проверяет `specSchema` везде, где оно
  входит (ответ ИИ, добавление, реестр с диска); запрос не уходит за `baseUrl`, ключ
  подставляет шлюз, перенаправления запрещены. Генерация - `claude -p --json-schema` с
  инструментами белым списком (`--tools WebFetch WebSearch`, `--restricted`, `--safe-mode`,
  `dontAsk`, без MCP) в своей пустой папке; запрет лишних вместо белого списка пропустил бы
  то, чего нет в запрете. Работа живёт в главном процессе (`AiConnectorDesk.state`), а не в
  окне.
- **Клиент Google - свой у человека, опубликованный на его домене** (ADR 0031): иначе
  войти могут только тестовые пользователи. Промпт настройки (`connectors.google.agentPrompt`)
  сначала создаёт клиент, потом спрашивает домен; без домена - тестовый режим с названными
  адресами, выдуманных ссылок в Branding нет, DNS - только добавление записей и с вопросом.
  Политика из промпта говорит правду о данных: поменялись инструменты Google - поправить её.
  Отдаётся промпт приложению ИИ ссылкой (`agent-links.ts`): схему и путь собирает главный
  процесс, из окна - только текст; ссылка кладёт промпт в поле ввода, отправляет человек.
- **Slack app - свой на рабочее пространство** (ADR 0032): MCP Slack пускает только внутренние
  и опубликованные в Marketplace приложения. Создаётся по ссылке с описанием
  (`slack-manifest.ts`): адрес возврата, разрешения - те, что Slack MCP объявляет сейчас (вход
  просит их все), и бот, без которого Slack не ставит приложение. MCP описанием не включить -
  это шаг человека.
- **Перенос из Claude Code сохраняет имена** серверов: на них завязаны правила и хуки
  человека; новое имя видно в списке. Одинаковые серверы с именами «начало-подпись»
  (playwright-1, playwright-2) встают одним своим типом. Конфиг Claude Code не трогается.
  `.mcp.json` - только у доверенной папки, отклонённые в Claude Code серверы не предлагаются, неодобренные
  помечены, и серверы проекта по умолчанию не отмечены. `${VAR}` раскрывается из оболочки,
  проба входа решает OAuth только по 401.
- Проверять вход вживую - в копии окна (`/dev`): у неё свой userData и свои коннекторы,
  коннекторы dev человека не трогать.
