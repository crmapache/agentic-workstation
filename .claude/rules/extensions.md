# Расширения IDE и магазин

Почему так - ADR 0091, карта - раздел «Расширения IDE» в `docs/architecture.md`.

- **Код расширения - только в песочнице.** Ни `node:vm`, ни `eval` в главном процессе, ни HTML
  расширения в окне. Всё, что расширение может, - ручка `ide.*`: метод в `host/*-methods.ts` с
  правом, функция в прелюдии (`engine/prelude-api.ts`), строка в `authoring/templates/ide.d.ts.txt`
  и `AGENTS.md.txt`. Ручка без строки в руководстве для ИИ не существует: ИИ о ней не узнает.
- **Аргументам песочницы не верим, как окну.** Разбор - `host/host-args.ts`, пути - только
  `host/project-files.ts` (открытый проект, настоящий путь), дерево вида и тема - `host/ui-tree.ts`.
- **Право - ступенью выше, а не в обход.** Новая ручка, которая читает чужое, пишет, говорит с
  сетью или запускает программу, - под правом; новое право - в `EXTENSION_PERMISSIONS`,
  `PERMISSION_RISK`, `KNOWN_PERMISSIONS` протокола магазина (держит тест), окне одобрения и
  руководстве. Хук может сузить (отклонить, переписать), но не расширить права разговора.
- **Хук не держит разговор.** Каждый хук - со сроком (`extension-hooks.ts`), упавший или
  опоздавший ничего не меняет. Без подписчиков ядро панелей идёт тем же путём, что без расширений
  (`guarding`, `rewriting`).
- **Пределы - числами в одном месте**: песочница - `engine/sandbox.constants.ts`, вклад -
  в своих методах, дерево - `UI_LIMITS`, пакет магазина - `PACKAGE_LIMITS`.
- **Интерфейс расширения - узлы дизайн-системы.** Новый узел: тип в `shared/extension-ui.ts`,
  схема в `host/ui-tree.ts`, компонент в `ExtensionSurface/parts`, строка в `ide.d.ts.txt`.
- **Магазин:** пакет - только текст по проверенным путям, отпечаток сверяется после скачивания,
  манифест разбирается разбором IDE. Запись - только подписанная ключом IDE (ключ - в
  хранилище ключей, открытым текстом не ложится). Своё расширение с тем же id магазин не затирает;
  обновление со шире правами ждёт одобрения. Код сервера идёт в Node без сборки: в `apps/store` и
  `packages/store-protocol` - импорты с `.ts` и только стираемый синтаксис (без свойств в
  параметрах конструктора).
- **Выкладка магазина** - `apps/store/scripts/store-deploy.sh`, только по прямой команде владельца.
